Diabetes Prediction using Decision Tree with Streamlit
Project Overview

This project predicts whether a person is likely to have diabetes using a Decision Tree machine learning model. The application includes an interactive Streamlit frontend where users can enter medical parameters and receive instant prediction results.

The model predicts:

Diabetic
Not Diabetic
Features
Train a Decision Tree Classifier on a diabetes dataset
Predict diabetes risk based on user input
Interactive and easy-to-use Streamlit web interface
Real-time prediction output
Fast and interpretable classification
Technologies Used
Python
Scikit-learn
Pandas
NumPy
